# WhiteDevil UI preview (Compose shell)

Static preview of the **Agent / Hub / You** layout after the Jetpack Compose migration and Agent polish pass.

## See it now

1. **Screenshot (easiest)** — open in GitHub or your IDE:
   - [`whitedevil-ui-snapshot.png`](./whitedevil-ui-snapshot.png)

2. **Interactive mock (3 phone frames)** — download [`whitedevil-ui-preview.html`](./whitedevil-ui-preview.html), then double‑click it (or drag into Chrome). Works offline; no server required.

## Not the same as the APK

This folder is a **design mock** for layout and colors. The real app is built from `android/` on branch `cursor/full-device-integration-1b6f` ([PR #3](https://github.com/WhiteDevil-93/White-devil-repo-4/pull/3)).
