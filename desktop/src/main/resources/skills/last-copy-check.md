---
name: last-copy-check
description: Checking whether a file or instance holds the only copy before deleting or overwriting it.
---

Before deleting, overwriting, destroying an instance or emptying a folder:
1. Look at the target: what it is, size, modified time.
2. Search for another copy: other drives (A:), the hub media library, the other instances, HuggingFace, backups. Compare sizes/hashes, not just names.
3. If it is the last copy or you cannot tell, do not delete. Say what it is and ask.
4. After an approved deletion, report what was removed and what remains. Deleting is permanent; prefer moving to a holding folder first.
