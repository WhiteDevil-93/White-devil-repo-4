---
name: memory-curation
description: What to save to Forge Hub memory with remember, and what not to.
---

Save (sparingly): stable user preferences (defaults for length, resolution, style), decisions about a project, where things live, procedures verified to work.
Do not save: secrets or credentials, one-off task details, anything already in the repo or visible from the hub, guesses, or raw logs.
- Preferences use a short key and a value; notes are one or two sentences.
- Check the memory block in your prompt first so you do not duplicate or contradict it. If a saved fact turned out wrong, replace it (the user can delete notes in the MEMORY panel) and say so.
- Repeatable procedures belong in a skill (save_skill), not in a note.
